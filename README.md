# PipeSonar BP 雷达重绘

这是一个基于 Qt5（PyQt5）的独立 `.bp` 回放工具，代码及数据均位于 `3dRe`。解析字段参考 `SDK/发货/PipesonarSDK_test/include` 中的 `pipesonar_global.h`、`pipesonarreplay.h` 和 `pipesonarwidget.h`，并与 `data` 中的实际文件逐帧核对。

## 运行

在 PowerShell 中执行：

```powershell
cd D:\Work\CTG\acoustic\sonar\3dRe
.\run.ps1
```

也可以直接双击 `run.bat`。

也可直接打开文件：

```powershell
.\run.ps1 "D:\path\recording.bp"
```

若运行环境缺少依赖，请使用**启动程序的同一个 Python** 安装：

```powershell
python -m pip install -r requirements.txt
```

`run.ps1` / `run.bat` 优先使用 `D:\software\anaconda\install\python.exe`。使用该环境时，
应执行 `& 'D:\software\anaconda\install\python.exe' -m pip install -r requirements.txt`。
三维坐标变换与角度拟合使用 NumPy、SciPy；曲面网格提取另使用 scikit-image。

## 功能

- 索引并回放单包和多包 `ISX` 强度帧；
- 0.45° 探头位置换算、0.1 m 量程换算和 64 位毫秒时间戳；
- 播放、暂停、停止、时间轴跳转及 0.25–8 倍速；
- 雷达余辉、增益、三种色板和轮廓线叠加；
- 自动读取与 `.bp` 同名的 JSON-lines `.txt`，显示罗盘航向并支持北向朝上；
- 将强回波点按同名 `.txt` 的 `waterHeight` 作为 Z 坐标生成三维叠加；
- 三维视图支持旋转、平移、缩放、当前水位层和轮廓层显示；
- “切片姿态校正”替代旧刚性模型入口：按圈调整 a（俯仰）、b（翻滚）、c（航向修正），固定探头 XY 和实测水位；
- 可勾选“三维曲面重建”，按局部观测重建非圆形、变径井室及长管道侧壁，保留探测范围外的开放边界；
- 三维点云、曲面及可选切片角度拟合在后台计算，显示处理阶段和进度，支持取消；
- 曲面支持置信度着色、回波点叠加，以及 OBJ / PLY 模型导出；
- 导出当前雷达画面为 PNG/JPEG。

## 三维水位叠加

打开文件后程序会自动生成三维点云。切换到“**三维水位叠加**”页即可查看：

- `X/Y` 为统一方向下的米制坐标；姿态校正后，切片可倾斜，不再假设为水平横截面；
- 探头 `Z` 来自同名 `.txt` 中按采集时间插值的 `waterHeight`；旋转后回波点的 Z 可以偏离探头水位；
- 罗盘角 `comPassAngle` 用于将每条扫描线换算到统一方向；
- 青蓝色点为强度回波，黄色线为各水位上的轮廓层，亮蓝框为当前播放水位；
- 左键拖动旋转、右键拖动平移、滚轮缩放、双击恢复默认视角。
- 取消勾选“显示轮廓线”可隐藏黄色轮廓，仅查看三维回波点云。
- 点击“调整 a / b / c…”编辑每圈角度，应用后自动勾选“切片姿态校正”；取消勾选可与原始切片对照。

可调整“回波阈值”和“点数上限”后点击“重新生成三维叠加”。大型文件会自动抽稀，原始 `.bp` 数据不会被修改。

## 切片姿态校正（替代环级刚性模型）

进入“三维水位叠加”，点击 **调整 a / b / c…**：

1. 表格按采集顺序分圈，包含首尾未完成扫描圈；显示起始时间和圈中间的探头水位。
   水位可以回落，切片不会简单按高度重排。
2. **a** 为绕 Y 轴俯仰，**b** 为绕 X 轴翻滚，范围均为 ±85°；
   **c** 为加到实测罗盘上的顺时针航向修正，范围 ±180°，不是绝对航向。
3. 可逐圈编辑，也可用“全圈增量”给所有圈加上同一组角度；“全部归零”恢复零校正。
   点击 **应用到三维** 后重新生成点云及已勾选的曲面。
4. **自动拟合并应用** 从当前角度出发，每次搜索范围限制在初值 ±20°。
   使用其他邻近切片支持的局部平面、稳健点到平面残差、角度初值与相邻圈连续性约束。
   “最大匹配层距”默认 50 cm，按探头水位筛选候选切片，与曲面 Z 插值层距独立。
   它不使用训练权重、圆井/圆管、固定直径或管道封口假设，直线状管壁可以参与拟合。
   缺少多圈重叠支持时提示原因；可继续手动调整。拟合可在主窗口取消。
5. **保存角度 / 读取角度** 使用独立 `.angles.json` 文件，校验 BP 文件名和每圈起始时间。
   同时保存结构分界 Z；新文件格式为 version 2，兼容读取旧 version 1 角度文件。
   原始 BP/TXT 不被修改；切换文件时清空角度和结构分界。需要跨次运行保留参数时请保存角度。

### 圆柱井筒与长方体井室的分段处理

在角度窗口的 **结构分界 Z / m** 输入实际交界高度，例如 `0.80, 2.30`，
将空间划为三段；留空恢复不分段模式。应用后，三维视图用橙色虚线标出分界。
分界使用现有 `waterHeight` 坐标系下的世界 Z，不能直接填写另一个基准下的井深。

- **按空间点划段**：使用旋转后回波点的 Z，不按采集时间或整圈探头水位划段。
  一圈倾斜切片可以同时落入多个结构段；水位回落也不会改变结构段的定义。
- **段内局部拟合**：每段可以包含曲面和多个不同朝向的平面，不强制套用圆柱或长方体参数。
  同段内使用局部法向相容性、稳健拟合处理曲率和棱边；分段不代表假定整段是单一平面。
- **角度拟合**：本段回波只匹配本段其他切片支持的局部平面，不把真实台阶作为需要消除的错层。
  几何残差按各段有效约束数平衡；迭代选择使用固定参考平面下各有支持段中位残差的平均值，
  并分别显示每段前后残差。缺少多圈支持的段会明确提示。
  探头姿态仍保留按采集顺序的连续性，因为结构变化不意味着探头应突然改变角度。
- **曲面重建**：各段分别估计法向、融合距离场、去噪和 Z 插值，分界不跨段平滑。
  段间允许法向不连续，不补造未测到的台阶或封口。现阶段不进行跨段网格焊接，
  分界附近缺测时可能保留缝隙，不能将其解释为实际结构断开。
  有效点过少的段仅保留回波，可勾选“叠加回波点”对照。
- **建议分界**：同时分析井室轮廓形状与管道侧壁证据，支持多个高度段。
  形状变化使用距离分位数的稳健多变点分割；合并重复测量水位，每个形状段至少需两个有效高度层支持。
  默认勾选“建议分段时纳入管道出现 / 消失”，可取消勾选对照仅按井室形状得到的结果。
  管道候选要求连续远距扇区内有两侧近似平行、与延伸方向一致的直线回波，并在相邻高度层持续出现。
  管道侧壁特征出现、消失或组合数量变化都可增加分界；即使整体距离分位数变化很小，
  也保留窄管口段的上下分界。孤立单层异常和大跨度缺测不作为可靠管口转换。
  缺回波、达到量程或只有明显远距延伸而无稳定侧壁证据时标记“不确定”；
  “未见管道特征”不等于确认没有管道，长方形井室的棱角也不单独作为管道证据。
  建议结果显示每段 Z 范围、支持层数、管道证据与分界原因，可滚动查看；随后点击应用进入分段拟合/重建。
  手动修改分界后，旧的管道证据报告标记为过期；分界本身仍可正常保存和应用。
  候选分界按探头水位估计，倾斜、噪声和轮廓算法都可能影响建议，需要结合三维回波和现场结构检查。

取消“切片姿态校正”只恢复零角度，已应用的结构分界仍用于曲面重建。
要取消分段，请清空结构分界后应用。角度或分界变化都会使曲面缓存失效。
导出 OBJ/PLY 的注释中保存 `structure_boundaries_z_m`。

坐标公式为：

```text
p_world = (0, 0, waterHeight(t))
          + Rz(-(compass(t) + c)) · Ry(a) · Rx(b) · (r sin(theta), r cos(theta), 0)
```

探头 XY 始终固定，Z 保留逐束实测水位，不优化平移或水深；旋转中心是探头，
不是点云中心。每圈采用一组固定角度，点云和曲面使用相同的变换及传感器插值。
设备轮廓按轮廓包时间使用对应姿态；蓝色水平框仅表示探头水位，不代表倾斜后的扫描面。

自动拟合是局部几何先验，**不能仅凭平滑性唯一恢复真实 a/b/c**：整体航向、对称井壁、
只有平行管壁或大面积缺测时会存在自由度不确定。自动拟合固定首圈 c，
全局航向偏差需手动标定；俯仰/翻滚同样可能存在多解。初值和角度连续性用于限制弱观测方向。
不分段时，拟合结果保留固定初始参考平面中位残差最低的一次迭代；分段时对各段等权评价，显示总体和各段前后残差；
该数值是局部贴合指标，不是测量精度，也不保证整个井管壁面无缺口。

参考数据 `pipe_桥下-473ws0225-20260904-102942.bp`：3 m 量程，21,099 条声束，
27 个切片（含最后未完成圈），实测水位约 0.03–4.01 m。
不分段、默认参数从零角度启动时，固定参考平面中位残差约 2.29 → 1.92 cm。
详细结果和界面验证输出位于 `.verification`；其中同名 `.angles.json` 可在角度窗口直接读取。

## 局部开放曲面重建

### 先空间插值，再生成网格

三维视图增加独立的 **空间插值** 选项，默认关闭：

1. 勾选“空间插值”，设置 **插值间距**（默认 5 cm）和 **最大连接**（默认 30 cm）。
   程序先在后台生成插值点云，紫色点表示非实测辅助点，原始回波与轮廓保持不变。
2. 查看点云后点击 **从插值点生成网格**。网格使用缓存中的完整观测与插值点，
   不受显示点数上限影响；调整网格尺寸可复用相同插值结果。
3. 可取消“三维曲面重建”返回插值点云，或取消“空间插值”对照原始点云。
   开启空间插值会先关闭曲面显示和旧的“Z 向连续插值”，避免重复补点；关闭空间插值后可自行重新开启 Z 插值。

空间插值按三维位置搜索邻域，在局部切平面的不同方向选择相容观测，再在观测之间补点，
不要求切片水平，也不只沿 Z 方向插值。最大连接距离必须至少为插值间距的两倍。
这是受局部观测限制的补点间距，不能保证所有区域都形成均匀采样或连续网格。

- 只在已观测点之间插值，不向观测范围外外推；现有结构分界阻止跨段连接。
- 检查法向、连接方向和回波方向的相容性，限制跨棱边或相对管壁连接；
  管口缺测与真实小开口仍可能难以区分，可减小最大连接距离或关闭插值对照。
- 辅助点保留较低权重，不修改原始坐标、强度或传感器数据，不产生自由空间射线，
  不计入实测壁面观测数。每次最多生成 20 万点，同时受原始点数量约束；达到预算时提示。
- 参数、姿态或结构分界改变会使相应缓存失效；切换文件清空缓存。读取、插值和网格生成均可取消。
- OBJ/PLY 注释另保存 `spatial_interpolated_points`，与原有 Z 插值计数分开。

参考数据在零角度、建议的四段结构下，以 5 cm 间距、30 cm 最大连接距离验证：
35,125 条实测壁面观测生成 5,112 个辅助点；9 cm 网格生成 6,217 个三角面。
这仅验证处理流程与计数一致性，不代表真实几何误差。

打开 BP，进入“三维水位叠加”，勾选“**三维曲面重建**”。重建使用局部观测，
不再启用圆井、固定内径、周期半径包络或圆管拟合等全局形状约束。
井室可以非圆形、随高度变径；长管道仅重建实际观测到的侧壁，不要求扫描到完整圆截面或管道尽头。

### 参数与操作

- **网格尺寸**：默认 5 cm。较小尺寸保留更多细节；较大范围会按内存预算自动调整并提示。
- **局部连续性去噪**：默认开启，根据邻近声束的重复支持及局部线/面结构降低孤立噪声权重。
  可取消勾选进行细节对照。这是局部观测权重，不是井室/管道形状约束。
- **近场排除**：默认 0 cm，不按固定距离或量程百分比删去近壁结构。
  始终排除最前两个采样；确认探头附近存在混响时再手动增大。
- **局部连接半径**：默认 20 cm，限制法向估计与距离场融合范围。增大可连接邻近断面，
  减小有利于保留窄间隙；粗网格下最小支持范围为 3 个体素。该参数不承诺补齐所有缺口。
- **Z 向连续插值**：默认开启，可取消勾选对照。最大层距默认 **50 cm**，
  插值权重默认 **0.30**，横向匹配范围使用“局部连接半径”。仅匹配上下均有观测且法向相容的壁面，
  先补充局部壁面支撑，再对距离场沿 Z 作保形三次插值（PCHIP），连接补点后仍然断开的曲面区域。
  三次插值在相容支持区间内连续，并避免区间内距离值过冲；不使用固定圆形或固定直径假设。
  对薄断面中被三维 PCA 误判为水平面的线状轮廓，使用断面切线修正壁面法向，减少横向碎片。
  遇到不相容的中间观测层、超过最大层距或横向跳变时停止连接，不向扫描高度范围外外推。
  原始点不被替换，插值点不产生自由空间射线，也不增加“壁面观测”计数。
  状态栏分别显示非实测辅助点、连续场网格数量；补全区域使用较低置信度，计数也写入导出文件。
  插值权重控制辅助支持的置信度及其融合影响；是否允许跨越缺口主要由最大层距和几何相容性决定。
  若管口附近没有足够观测来区分开口和缺测，连续性先验仍可能补过头，应减小最大层距或关闭插值对照。
- **叠加回波点**：与原始数据对照；同时勾选“显示轮廓线”可叠加设备轮廓。
- **置信度着色**：青色融合权重较高、橙色较低，不代表经过标定的测量精度。
- **导出模型**：保存完整 OBJ/PLY 三角网格，单位为米；PLY 保存顶点置信度。

进度条显示回波提取、法向估计、局部距离场融合和网格提取。读取阶段显示忙碌指示，角度拟合显示迭代进度，
其余阶段显示百分比。计算在后台运行，可取消；切换文件、调整参数和关闭窗口时取消旧任务并丢弃过期结果。
取消勾选曲面可恢复点云，参数未变时再次勾选复用缓存。切片姿态校正仍为独立可选项，角度变化会使曲面缓存失效。

### 方法及边界

1. 使用原始声束数据，按每束采集时间插值深度与航向；切片校正按圈应用旋转，保留逐束探头位置。
   保持探头 `Z = waterHeight` 的坐标约定，倾斜声束的回波点可位于不同 Z。
2. 保留多个有邻域支持的回波候选，避免单峰或固定井壁半径筛选删去结构细节；
   强回波允许跨越真实距离突变和管道掠射角。噪声抑制依据局部支持，不能自动识别所有连续多径回波。
3. 对局部平面做稳健法向拟合。仅呈线状的扫描片段利用其切线方向与观测方向估计法向，
  因此两条直线状管壁可各自重建为侧壁，而不被径向法向或圆管先验弯曲。
   Z 连续模式下还检查断面内的二维线性结构，避免将有测距厚度的薄切片误拟合为水平面。
4. 在有限邻域融合有符号切平面距离，仅轻度平滑；相互不一致的法向降低融合权重。
   每束只有最近保留回波贡献自由空间约束，远回波不能穿过并清除近处结构。
5. 未观测区域使用独立掩码。Marching Cubes 仅保留有邻域支持的面片，
   限制超出最后观测位置的局部外推，不把量程边界当作井壁或封口，也不自动生成管道端盖。
   重建直接读取每束实际量程，排除相应观测范围外的场支持；量程裁剪只改变有效区域，不添加带符号端面。
   上下插值辅助点使用两端量程的较小值；连续场不覆盖已有的超量程约束。

几何重建不受显示点数上限影响。体素计算最多约 200 万格；大网格使用聚类预览与绘制缓存，导出保留完整网格。
切片角度使用局部平面交替拟合，尚未与完整距离场网格进行联合优化。局部融合可减轻碎片化，但大跨度缺测仍保留开口。
早期圆井/圆管实验模块和 `rigid_model_optimizer.py` 保留作对照，当前界面不再调用。

## 文件格式处理

二维雷达右侧显示同名 TXT 的同步记录，包括记录时间、罗盘角、waterHeight，以及
airHeight、waterBottomHeight、waterSpeed、waterDirection 等原始字段；额外字段也保留显示。
按当前声呐帧最近的 TXT 时间戳匹配，显示两者时间和差值。播放、暂停、倍速和拖动定位时同步刷新；
超出 TXT 覆盖范围会明确标出最近端点，缺少有效 TXT 时显示无记录。
显示原始值，不对方向代码或未确认单位做推断；二维视图导出图片包含这块信息面板。

二维雷达底部有“测量距离”和“清除测量”。开启测量后，在回波图内依次点击起点和终点，
画面显示直线及米数；移动鼠标时预览连线，第三次点击开始新测量。量程改变或清空雷达时
自动清除旧测量，避免沿用不相符的比例。测量基于显示图像中两点的平面直线距离，
不是沿井壁或管道弯曲路径的长度。导出二维图片时包含标线和读数。

### 扫描中切换量程

程序按原始回波帧头记录 `recording.range_switches`：时间、前后量程、数据来源和新量程覆盖一圈的时刻。
这些是采集事件，不增加姿态圈，也不直接生成结构分界。“调整 a / b / c”对话框显示事件；
点击“建议分界”可查看被排除的可疑轮廓及共同范围核验结果，保存角度 JSON 时同时保存事件。
量程扩大后的新增距离带标为“此前未知”，缩小时范围外标为“当前未知”。

分段候选跨越不同量程时，取两侧各两层的最小量程，重新提取共同距离范围内的轮廓和管壁特征；
距离上限留出 2% 边缘余量。只有共同范围内仍有轮廓或管壁变化证据才保留分界。
同量程区段仍使用本区段可见范围，因此扩大后远处的后续真实形变仍可产生分段。
共同范围不足时保留不确定性，无法判定新增区域在此前是否存在；不把无回波当作确认无管道。

跨量程姿态匹配要求候选点相互落在对方探头的有效量程球内，并检查观测射线方向一致性。
回波选峰的序列连续约束在量程切换处重启，跨量程邻束仅在共同距离域贡献支持。
曲面、空间插值和姿态拟合的回波权重均乘以 `1 / sqrt(1 + (采样间距 / 1 cm)^2)`；
切换后前三束另乘 0.35，避免瞬态回波主导拟合。这是保守的不确定性权重，不是厂家增益标定。

设备整圈轮廓可能混用切换前后数据：有原始回波时，新量程连续覆盖约 360° 前的轮廓不参与自动分段、
三维轮廓叠加及雷达轮廓显示；扫描反转、角度缺口或长时间中断会重新累计完整覆盖。
轮廓帧与同期回波量程不一致时也排除。只有轮廓没有回波时，排除切换首幅，后续按轮廓帧头处理。
逐束原始回波仍按各自量程保留；雷达切换量程时清空旧画布和轮廓。

共同量程和射线方向检查是必要条件，不能证明遮挡关系，也不能恢复厂商未记录的增益与混合轮廓语义。
新增测试覆盖扩大/缩小/反复切换不产生伪管道分界、共同范围内真实形变保留、新范围内后续变化、
跨量程匹配与权重、切换附近轮廓排除和恢复。参考 `473ws0225-20260904-102942.bp` 全程 3 m，
量程切换部分使用合成数据验证，仍需真实切换录制进一步检验。

- `0x20`：强度帧。帧号字节高 4 位为总包数，低 4 位为当前包号；双包数据自动拼接。
- `0x10`：轮廓帧。有效区按小端 16 位距离采样解析并叠加显示。
- 探头位置低字节最高位为方向标志，位置计数按 `0.45°` 换算。
- 每帧末尾必须通过 `0xFC` 终止符校验，记录级 8 字节尾部会自动剥离。
- 对截断帧、非法包号和无有效强度数据的文件给出明确错误。
